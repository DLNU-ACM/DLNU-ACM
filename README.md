# 🤔 这是什么？

欢迎访问大连民族大学 ACM 工作室的公共仓库。本仓库面向校内所有对算法竞赛、程序设计感兴趣的同学开放。仓库存放有常用算法模板、算法笔记、辅助工具、校内比赛题目题解和工作室各类奖项等。

如果你是：

- 对算法竞赛有兴趣的同学
- 想要入门数据结构与算法的同学
- 正在/想要准备XCPC、蓝桥杯、百度之星或天梯赛等竞赛的同学

那么这个仓库里的内容对你一定很有用！
